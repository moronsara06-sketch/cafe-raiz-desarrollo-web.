# Café Raíz — práctica de desarrollo web

Proyecto educativo de una cafetería ficticia desarrollado con HTML, CSS y JavaScript.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: estilos, Flexbox, Grid y diseño adaptable.
- `script.js`: interacciones, calculadora de pedido y validación básica del formulario.
- `assets/`: ilustraciones SVG locales.
- `capturas/`: evidencias visuales del proceso y vistas de la página.

## Cómo abrir
Abre `index.html` en un navegador moderno. No necesita dependencias ni conexión a internet para funcionar localmente.

## Nota
El formulario es demostrativo: no envía datos a un servidor ni procesa pagos.

## Decisiones de construcción
Elegí una cafetería ficticia porque permite organizar productos y precios en una interfaz sencilla. Separé HTML, CSS y JavaScript para mantener el código ordenado; usé Flexbox para alinear elementos, Grid para distribuir secciones y media queries para adaptar la interfaz a pantallas pequeñas. JavaScript añade interacciones, cálculo del pedido y validación básica. Las ilustraciones SVG se guardan localmente para evitar depender de imágenes externas.
