CAFÉ RAÍZ - PROYECTO EDUCATIVO HTML, CSS Y JAVASCRIPT

Archivos:
- index.html: estructura y contenido de la página.
- styles.css: estilos, modelo de caja, Flexbox, Grid y diseño adaptable.
- script.js: menú móvil, botones de productos, calculadora y validación del formulario.
- assets/: ilustraciones SVG para los productos y la cabecera.
- capturas/: evidencias visuales de las etapas de trabajo.

Para abrir la página, haz doble clic en index.html o abre ese archivo desde un navegador.
No requiere instalación ni conexión a Internet para funcionar.

Nota: es una interfaz educativa de demostración. No procesa pagos ni envía formularios a un servidor real.
